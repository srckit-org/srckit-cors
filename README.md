# srckit-cors

> Part of [srckit](https://github.com/srckit-org/srckit) — developer tools suite

Test URLs for CORS configuration, understand preflight requests, and learn how Cross-Origin Resource Sharing works.

## Features

- **Tester** — Send simple GET and OPTIONS preflight requests to any URL, display CORS headers and status
- **Preflight** — Visual explanation of the preflight flow with request/response examples
- **Explain** — FAQ covering common CORS questions (what, why, how to fix)

## Tech Stack

React 19 · MUI 9 · Tailwind CSS 4 · TypeScript 6 · Vite 8

## Getting Started

```bash
npm install
npm run dev
```
